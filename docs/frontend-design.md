# 前端设计

技术栈：HTML + CSS + JavaScript（原生，无框架）

## 页面结构

```
前端页面（Nginx 托管）
├── index.html          # 秒杀活动列表页
├── seckill.html        # 秒杀详情 + 下单页
└── admin.html          # 管理后台（活动管理）
```

## 秒杀列表页 (index.html)

```
┌──────────────────────────────────────────┐
│  秒杀活动列表                    [刷新]    │
├──────────────────────────────────────────┤
│ ┌────────────────────────────────────┐   │
│ │ 🟢 iPhone 16 秒杀                 │   │
│ │ 原价: ¥6999  秒杀价: ¥4999        │   │
│ │ 剩余: 850/1000                    │   │
│ │ 2026-06-01 10:00 ~ 12:00          │   │
│ │ [即将开始 / 立即抢购 / 已结束]      │   │
│ └────────────────────────────────────┘   │
│ ┌────────────────────────────────────┐   │
│ │ 活动2 ...                         │   │
│ └────────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

- 轮询活动列表，展示活动状态和剩余库存
- 根据 status 显示不同按钮文案

## 秒杀详情页 (seckill.html)

```
┌──────────────────────────────────────────┐
│  ← 返回    iPhone 16 秒杀                │
├──────────────────────────────────────────┤
│  商品: iPhone 16 256G                    │
│  原价: ¥6999                             │
│  秒杀价: ¥4999                           │
│  剩余库存: 850                           │
│  活动时间: 2026-06-01 10:00 ~ 12:00      │
│                                          │
│  ┌──────────────────────────────┐        │
│  │  [滑块验证码 / 图片验证码]    │        │
│  └──────────────────────────────┘        │
│                                          │
│  [  立即抢购  ]                           │
│                                          │
│  ┌──────────────────────────────┐        │
│  │ 订单状态: 排队中...           │        │
│  │ 订单号: SK20260601...        │        │
│  └──────────────────────────────┘        │
└──────────────────────────────────────────┘
```

流程：
1. 点击「立即抢购」→ 弹出验证码
2. 验证通过 → POST /api/seckill/order
3. 返回 PENDING → 轮询 GET /api/order/status/{orderNo}
4. 显示最终结果（成功/失败/超时）

## 管理后台 (admin.html)

```
┌──────────────────────────────────────────┐
│  秒杀管理后台                             │
├──────────────────────────────────────────┤
│  [+ 新建活动]                            │
│                                          │
│  活动列表                                │
│  ┌────┬──────────┬──────┬──────┬─────┐  │
│  │ ID │ 名称     │ 库存 │ 状态 │ 操作 │  │
│  ├────┼──────────┼──────┼──────┼─────┤  │
│  │ 1  │ iPhone.. │ 850  │ 进行 │ 编辑 │  │
│  └────┴──────────┴──────┴──────┴─────┘  │
│                                          │
│  [初始化库存] [查看订单]                   │
└──────────────────────────────────────────┘
```

功能：
- 活动 CRUD
- 手动初始化 Redis 库存
- 查看活动关联订单

## 交互要点

- 秒杀按钮点击后立即禁用，防止重复提交
- 库存为 0 时按钮置灰
- 订单轮询间隔 500ms，超过 10s 提示超时
- 验证码校验失败可重试
